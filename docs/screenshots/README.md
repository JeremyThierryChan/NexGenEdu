# 截图目录

README 与各手册里引用的图片放在这里。当前仓库**还没有任何截图**（README 里的首页图仍是注释状态）。

## 怎么放

1. 按下面的名字命名，存成 `.png`（宽度 1200–1600px 足够，单张控制在 500 KB 以内）：

   | 文件名 | 内容 |
   | --- | --- |
   | `home.png` | 宣传网站首页首屏 |
   | `courses.png` | 课程页（六栏目 → 卡片） |
   | `course-detail.png` | 某张课程卡片页（体现「同一卡片的标签 = 不同阶段」） |
   | `quote.png` | 智能报价页（选好之后的结果区） |
   | `admin-dashboard.png` | 后台今日概览 |
   | `admin-lessons.png` | 后台课程安排（排课表单 + 冲突提示） |
   | `admin-pricing.png` | 后台报价页（教师分成规则与人数对照表） |

2. 在 README 或手册里用相对路径引用，例如：

   ```md
   ![首页](docs/screenshots/home.png)          <!-- README.md 里 -->
   ![今日概览](./screenshots/admin-dashboard.png)  <!-- docs/*.md 里 -->
   ```

   注意两种文件的**相对路径不同**：README 在仓库根，手册在 `docs/` 里。

## 拍之前请注意

- 用**示例数据**截图，别截真实学生的姓名、电话、微信、成绩 —— 这些一旦提交就进了 git 历史，很难彻底删掉；
- 后台截图请**先退出登录再截**也不行（登录后才有内容）：截完自查一遍画面上没有真实信息；
- 建议在浏览器窗口宽度 1440px、缩放 100% 下截，页面观感与线上一致。
