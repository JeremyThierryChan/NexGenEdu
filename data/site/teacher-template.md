# 教师信息采集表

> **用法**：复制下面「教师模板」整块内容 → 填写 → 把填好的文件发给我，我会把它合并进
> `data/site/content.md` 的教师页。填几份都可以，一并发我即可。
>
> 不确定怎么填的字段直接留空或写「待补」，我会保留格式并在页面上按空值处理。

## 填写须知（先看这段）

### 必填字段的写法

| 字段 | 是否必填 | 写法 | 示例 |
| --- | --- | --- | --- |
| `姓名` | 必填 | 会显示在卡片与详情页，请写页面上的称呼 | `王明` 或 `王老师` |
| `科目` | 必填 | 多个科目用**逗号**分隔；只能是下面「可选科目」里的名称 | `数学, 物理` |
| `教龄` | 必填 | 只写年限 | `8 年` |
| `简介` | 必填 | **一句话**，显示在卡片上，建议 20–40 字 | `擅长把抽象概念讲成学生能听懂的语言。` |

### 选填字段

| 字段 | 是否填 | 说明 |
| --- | --- | --- |
| `职务` | 选填 | 如「数学教研组长」。不填就删掉这一行，页面上会自动隐藏 |
| `排序` | 选填 | 数字，**越小越靠前**。不填则按文件顺序排在最后 |
| `状态` | 选填 | 填 `在职`（默认，会展示）或 `离职`（保留在文件里但页面不展示） |
| 详细介绍 | 选填 | 字段之后、下一个教师之前的文字，显示在教师详情页。可写 1–3 段 |

### 可选科目（必须完全一致，否则页面标签会对不上）

```
语文  数学  英语  科学  社会  物理  化学  生物
政治  历史  地理  技术  雅思  法语  德语  意大利语  西班牙语
```

> 一位教师可跨多个科目，例如「数学, 物理」——这也符合我们「全科教师」的定位。

### 格式上的三个注意

1. `### 姓名` 必须顶格写，前面不要有空格
2. 字段行写成 `#### 科目: 数学`（**全角冒号或半角冒号都可以**）
3. 详细介绍直接写在字段下方，段与段之间空一行；支持 `**粗体**` 与 `- 列表`

### 可选能力（如实填写，页面上会体现）

- 能带哪些学段？（小学 / 初中 / 高中）
- 带过几届毕业班？有没有竞赛、雅思经验？
- 教学风格一句话（例如「先确认学生卡在哪一步，再决定讲什么」）
- 是否有照片（有的话把图片发我，放进 `public/images/` 后在教师分组里填文件名）
